# 業務規則：外送範圍與運費計算

## 1. 服務範圍校驗
系統應根據顧客輸入的「外送距離」決定是否受理訂單：
- **<= 3 公里**：正常受理，免收運費。
- **3 ~ 5 公里**：條件受理（進入運費判斷）。
- **> 5 公里**：**強制攔截**，回覆：「抱歉，天下茶屋目前配送上限為 5 公里。」

## 2. 運費加收邏輯 (3~5 公里區間)
當距離落點在 **3 至 5 公里** 之間時，依據訂單小計金額判斷：
- **小計 < $300**：加收 **$50** 運費。
- **小計 >= $300**：**免運費** ($0)。

| 距離 (d) | 金額 (total) | 運費 (Fee) | 執行動作 |
| :--- | :--- | :--- | :--- |
| d <= 3km | 不限 | 0 | 受理訂單 |
| 3 < d <= 5km | < 300 | 50 | 受理訂單並加價 |
| 3 < d <= 5km | >= 300 | 0 | 受理訂單並免運 |
| d > 5km | 不限 | - | 攔截訂單 |
